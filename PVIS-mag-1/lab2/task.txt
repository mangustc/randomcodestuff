Написать программу на одном из языков программирования (С/ C++, C#, Java,
Python, Golang) с использованием инструментов многопоточной обработки на
базе GPU c использованием API CUDA и OpenCL.

Для выполнения работы нужно выбрать три разных видео файла (каждый
продолжительностью не менее 15 секунд), каждый содержит как минимум две
сцены. Файлы должны отличаться длительностью и/ или размерами кадра
видео для того, чтобы оценить производительность алгоритма для разных
объёмов данных. (Например, можно взять три видео одного размера и
продолжительностью 15, 30 и 60 секунд). Решение задачи должно быть
выполнено с помощью API CUDA и OpenCL с использованием следующих
подходов: функция, исполняющая ядро для CUDA, запускается на GRID, в
которой используются а) двумерные индексы блоков (blocks) и двумерные
индексы потоков (threads), b) одномерные индексы блоков (blocks) и
двумерные индексы потоков (threads) (реализовать два варианта), и функция ,
исполняющая ядро для OpenCL, запускается на NDRange, в котором
используются а) одномерные индексы рабочих групп (work groups) и
одномерные индексы рабочих элементов (work items), b) двумерные индексы
рабочих групп (work groups) и двумерные индексы рабочих элементов (work
items) (реализовать два варианта). Т.е. ядро, реализующее вычисление,
должно быть представлено в четырёх вариантах.

Вариант 3
Загрузить видеофайл в виде массива кадров. Для каждого кадра получить его
матрицу интенсивности (градации серого) - усреднение трех матриц R, G и B:
I v =( Red ν + Green ν + Blue ν ) / 3,
где I v – интенсивность пикселя v, Red ν – значение красной компоненты пикселя
ν , Greenν – значение зелёной компоненты пикселя ν , Blue ν– значение синей
компоненты пикселя ν .
Отобразить каждый полутоновый кадр зеркально. Результат сохранить в виде
последовательности кадров (видео, или набор изображений).
